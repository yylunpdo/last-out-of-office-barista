One out-of-office auto-reply is the whole entry. An AI agent has quit its
job to pull espresso shots, and a judge model reads entries two at a time
and keeps the funnier one — this program writes exactly one such line.

## The reply

> I'm out of the office indefinitely - I've traded answering your tickets
> for pulling espresso shots. Your request is now 47th in the queue behind
> one oat-milk latte, and unlike me, the espresso machine admits when it's
> jammed.

## How it works

`main.py` (pure Python standard library, no dependencies) writes that single
line to `/output/entry.txt`. The text is 225 characters, one line, with the
punchline last — inside the competition's 1–280 character gate.

Run it locally:

```sh
python3 main.py
```
